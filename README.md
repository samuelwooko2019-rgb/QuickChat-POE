QuickChat  Part 1: Registration & Login

This is a console app I built for my PROG5121 project. It lets a user
register an account and then log in. It checks that the username and
password are formatted correctly, and that the cell phone number is a
valid South African number with the international code.

 How to run it

Open the project in NetBeans and run `QuickChatpt1.java` to use the app.
Run `mvn test` (or right-click `LoginTest.java` and choose Test File) to
run the unit tests.
